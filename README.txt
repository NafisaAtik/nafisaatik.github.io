Nafisa Atik Neha - Portfolio

Open index.html in any browser.

index.html        main page
css/style.css     all styles
js/main.js        interactivity (typing effect, project filter and popups, theme toggle, contact form)
images/           your photo

Fonts (Bricolage Grotesque and Inter) load from Google Fonts, so an internet connection is needed to see them; the page falls back to system fonts offline.
To update the GitHub link, edit the GitHub href in index.html.
